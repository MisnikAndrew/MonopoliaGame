# Монополия онлайн

Сетевая Монополия на 2–6 игроков (в том числе с ботами). Go + WebSocket на сервере, чистый HTML/CSS/JS в браузере — без сборки и зависимостей на клиенте. Всё вшито в один бинарник.

## Запуск

```bash
go run .              # http://localhost:8080
go run . -addr :80    # другой порт
go test ./...         # правила, боты проходят целые партии на всех полях
```

Создайте комнату, отправьте друзьям ссылку или 5-буквенный код, при желании добавьте ботов и выберите поле:
**Улицы Москвы · Города США · Города России · Страны мира**.

## Деплой (по образцу TriviaGame)

```bash
deploy/deploy.sh root@194.87.118.85            # http://194.87.118.85:8080
PORT=80 deploy/deploy.sh root@194.87.118.85    # если 80 свободен
```

Скрипт собирает linux-бинарник, заливает по SSH, ставит systemd-сервис `monopolia` и проверяет доступность снаружи. Пароль спрашивает сам ssh, нигде не хранится. Повторный запуск — обновление. Если снаружи не отвечает — откройте порт в файрволе панели хостинга.

## Правила

Классические: 1500 на старте, +200 за круг, дубли (три подряд — тюрьма), тюрьма (штраф 50, карточка, дубль; после трёх неудачных бросков выход бесплатно), покупка или аукцион, аренда (×2 за группу, дома до отеля, строить равномерно), станции и коммуналки, залог/выкуп, карточки «Шанс» и «Казна», налоги, банкротство (имущество уходит кредитору). Победитель — последний, кто не обанкротился.
Между игроками: в свой ход можно нажать на чужую улицу и предложить владельцу продать её за вашу цену или попросить выставить на аукцион (владелец принимает, отказывает или отвечает аукционом). Нельзя продавать заложенные поля и улицы с постройками.
Не реализовано: полноценный обмен (поле на поле, деньги), лимит на число домов в банке.

## Анимации

CSS 3D-кубики (кувыркание через Web Animations API), прыжки фишек по клеткам, перелёт в тюрьму, переворот карточки, всплывающие «+200 / −50» и плавный счётчик денег, пульсация купленных полей, конфетти победителя (своя реализация на canvas). `prefers-reduced-motion` учитывается.

## Источники картинок

Флаги стран и штатов США — [flagcdn.com](https://flagcdn.com) (флаги — общественное достояние). Остальное — эмодзи и CSS.

## Скины фишек

Картинки из папки `skins/` (png, jpg, webp, gif, svg) вшиваются в бинарник и появляются в лобби в разделе «Ваша фишка»; один скин — одному игроку. Новый скин: положите файл в `skins/` и перезапустите/задеплойте заново. Цвет игрока остаётся рамкой вокруг картинки.

## Боты

Оценивают улицы по близости к монополии и блокировке соперника, держат резерв по реальной угрозе (максимальная аренда у соперников), рано скупают всё и быстро выходят из тюрьмы, а поздно — сидят в ней; строят там, где дом даёт больше аренды за монету; под монополию закладывают лишнее; при долге расстаются с самым дешёвым; предлагают выкупить недостающую улицу группы и отвечают на предложения: за предложенную цену не продают: ниже оценки ×1,5 отказывают, от неё — выставляют на аукцион. В ход человека у полей ботов пишется эта цена («от N»). Логика — в `bot.go`.

## Режимы комнаты

Хозяин включает их в комнате до старта:
- **Аукцион на каждую клетку** — свободная улица не покупается по цене из карточки, а сразу уходит на торги (ставки от 10, первым ставит наступивший).
- **Налог на богатых** — каждые 5 кругов самый богатый (деньги + поля + дома) платит банку 10% состояния в начале своего хода.
- **Налог на доход** — банк берёт 13% с любого дохода (аренда, «Старт», карточки, продажа поля игроку или на аукционе); при балансе получателя больше 2000 — 15%, больше 5000 — 18%. Залог и продажа домов доходом не считаются.
